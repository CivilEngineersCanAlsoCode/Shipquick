# /033 Run Inspect & Adapt Workflow

**Goal:** Review progress of the Program Increment and identify improvement items for the next PI.

## PREREQUISITES

1. **PI Completion** -> Results and metrics available.

## INITIALIZATION

### 1. Performance Review

"Reviewing PI performance against objectives. What was achieved? What was missed?"

## EXECUTION

### 2. Quantitative Measurement

- Predictability Measure
- Quality metrics (defects, debt)

### 3. Problem Solving Workshop

- Root cause analysis
- Identify "backlog improvement" items
