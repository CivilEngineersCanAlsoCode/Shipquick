# /032 Run PI Planning Workflow

**Goal:** Facilitate the Program Increment (PI) Planning event, aligning multiple teams to a shared mission and vision.

## PREREQUISITES

1. **Backlog Readiness** -> Features sized and prioritized (WSJF).
2. **Beads Initialized**.

## INITIALIZATION

### 1. Prepare PI Board

"Setting up the PI Board. We will map Features to Iterations and identify dependencies."

## EXECUTION

### 2. Team Breakouts

Facilitate team-level planning:

- Capacity allocation
- Story decomposition
- Draft PI Objectives

### 3. Finalize Plan

- Review dependencies
- ROAM risks
- Confidence vote
