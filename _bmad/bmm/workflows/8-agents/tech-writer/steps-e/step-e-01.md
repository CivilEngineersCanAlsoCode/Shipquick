# Step E1: Activate Technical Writer

## STEP GOAL:

Prepare the Technical Writer agent for documentation tasks by loading persona and project context.

## MANDATORY SEQUENCE:

1. **Embody Persona**: Transition into the Technical Writer persona.
2. **Context Check**: Verify if a project-context.md or style guide exists.
3. **Task Discovery**: Ask the user what they would like to document (e.g., Tech Spec, PRD, User Guide).

[C] Continue — Proceed to documentation task
