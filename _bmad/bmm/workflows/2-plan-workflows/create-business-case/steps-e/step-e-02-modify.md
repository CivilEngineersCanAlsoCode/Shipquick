# Step E2: Modify Content

## STEP GOAL:

Allow the user to modify specific details of the Lean Business Case.

## MANDATORY SEQUENCE:

1. **Ask for Changes**: Ask the user what specifically they want to update (Problem, Hypothesis, Indicators).
2. **Draft Changes**: Show the proposed updated sections.

## MENU OPTIONS:

[C] Continue — Preview and Save changes
[R] Re-edit — Make more changes
