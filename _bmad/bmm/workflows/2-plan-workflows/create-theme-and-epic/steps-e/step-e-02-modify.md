# Step E2: Modify Content

## STEP GOAL:

Allow the user to modify specific details of the Theme or Epic while maintaining SAFe compliance.

## MANDATORY SEQUENCE:

1. **Ask for Changes**: Ask the user what specifically they want to change (e.g., hypothesis, business driver, description).
2. **Draft Changes**: Show the proposed updated sections.
3. **Maintain Compliance**: Ensure changes don't break parent-child links or core SAFe attributes.

## MENU OPTIONS:

[C] Continue — Preview and Save changes
[R] Re-edit — Make more changes
