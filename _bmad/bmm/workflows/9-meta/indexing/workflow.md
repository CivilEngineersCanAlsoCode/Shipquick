# Workflow: Indexing

## OBJECTIVE

Maintain a comprehensive and up-to-date index of all project documentation.

## PHASES

1. **Scanning**: Scan documentation directories for new or updated files.
2. **Metadata Extraction**: Parse file headers and summaries.
3. **Index Generation**: Update `index.md` with structured links and descriptions.

## MENU OPTIONS:

[R] Run Indexing — Execute the update
[V] View Index — Open current index.md
