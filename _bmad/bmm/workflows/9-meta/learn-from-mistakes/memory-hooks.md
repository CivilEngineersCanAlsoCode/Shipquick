# Memory Hooks: Learn From Mistakes

## Sidecar Integration

- **Primary Sidecar**: `global-learnings`
- **Sidecar Root**: `_bmad/_memory/global-learnings`

## Capture Strategy

- **Mistake Tracking**: Append any user-corrected assumptions or agent errors to `common-mistakes.md`.
- **Correction Efficiency**: Log speed of recovery to `recovery-metrics.md`.

## Loading Hook

- Always read `common-mistakes.md` during the "Mistake Audit" phase.
