# Workflow: PI Planning

## OBJECTIVE

Facilitate a structured Program Increment (PI) Planning event.

## PHASES

1. **Preparation**: Backend readiness and backlog prioritization.
2. **Draft Plan Review**: Teams present draft plans and risks.
3. **Management Review & Problem Solving**: Address bottlenecks.
4. **Final Plan Review**: Finalize objectives and commitment.

## OUTPUTS

- PI Objectives
- Program Board (Dependencies)
- ROAMed Risks
