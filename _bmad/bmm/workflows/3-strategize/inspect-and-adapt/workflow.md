# Workflow: Inspect & Adapt

## OBJECTIVE

Review PI progress and identify improvement items.

## PHASES

1. **PI System Demo**: Showcase completed work.
2. **Quantitative Measurement**: Review predictability and quality metrics.
3. **Retrospective**: Identify areas for improvement.
4. **Problem Solving Workshop**: Root cause analysis and action items.

## OUTPUTS

- Continuous Improvement backlog items
- PI Performance Report
