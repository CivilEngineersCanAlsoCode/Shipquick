# Step E-Edit.01: Assess Analytics Data

## Purpose
Load the analytics review artifacts and identify what needs correction or update.

## What to Do

1. **Load Current Analytics Data:**
   - Read the existing analytics report for the review period
   - Load engagement scores and performer rankings
   - Load captured insights and strategy adjustments

2. **Identify Issues:**
   - Check for incorrect or missing engagement metrics
   - Check for miscalculated engagement scores
   - Check for incomplete insights or missing user observations
   - Check for stale or outdated strategy adjustments
   - Note any posts that were added or removed after the initial review

3. **Present Assessment to User:**
   - List what was found and what appears to need correction
   - Ask user to confirm which items need editing:
     - "Metrics need updating (new Chrome Extension data available)?"
     - "Scores need recalculation?"
     - "Insights need revision?"
     - "Strategy adjustments need updating?"

4. **Build Edit Plan:**
   - Create a list of specific edits to apply
   - Prioritize: data corrections first, then insights, then strategy

## Output
- Assessment summary with identified issues
- Edit plan confirmed by user
- Ready to proceed to apply edits
