# Step E-Edit.02: Apply Corrections

## Purpose
Apply corrections to analytics data, insights, or strategy adjustments, then re-validate.

## What to Do

1. **Apply Metric Corrections:**
   - If new Chrome Extension data is available, update engagement metrics
   - Recalculate engagement scores: `likes×1 + comments×3 + shares×2`
   - Re-rank top and bottom performers based on updated scores

2. **Apply Insight Corrections:**
   - Update or add user insights as directed
   - Revise AI observations if underlying data changed
   - Ensure insights still align with the corrected data

3. **Apply Strategy Adjustments:**
   - Update strategy recommendations based on corrected analysis
   - Add new adjustments if the corrected data reveals different patterns
   - Remove adjustments that no longer apply

4. **Regenerate Report:**
   - Update the analytics report with corrected data
   - Ensure all template fields reflect the latest values
   - Update the generation timestamp

5. **Re-Validate:**
   - Run through the validation checklist (`steps-v/step-01-validate.md`)
   - Confirm all quality gates pass with the corrected data
   - Present updated validation summary to user

6. **Confirm with User:**
   - Show a diff summary of what changed
   - Ask user to approve the corrections
   - If approved, save the updated artifacts

## Output
- Corrected analytics data and recalculated scores
- Updated insights and strategy adjustments
- Regenerated analytics report
- Validation summary showing PASS

## Next Step
- If validation passes: Analytics review edit complete.
- If validation fails: Return to step-01-assess.md to reassess remaining issues.
