# Analytics Review — Quality Checklist

## Pre-Review Checks (4)

- [ ] Published posts exist for the selected review period
- [ ] Chrome Extension data is available (likes, comments, shares collected)
- [ ] Notion KPIs database is accessible via n8n webhook
- [ ] User is available for interactive discussion (E.3–E.4)

## Analysis Checks (5)

- [ ] Engagement scores calculated using correct formula: `likes×1 + comments×3 + shares×2`
- [ ] All published posts in the period have scores (no posts skipped without reason)
- [ ] Top performers identified (top quartile by engagement score)
- [ ] Bottom performers identified (bottom quartile by engagement score)
- [ ] Trends documented (format, timing, topic, trajectory)

## Discussion Checks (4)

- [ ] User asked about what worked and what surprised them
- [ ] AI observations presented (topics, formats, timing patterns)
- [ ] User insights captured verbatim (not paraphrased or invented)
- [ ] Strategy adjustments co-created with user (not AI-imposed)

## Post-Review Checks (5)

- [ ] Analytics report generated using the template
- [ ] Insights saved for next A-Ideation cycle reference
- [ ] Recommendations for next cycle documented (topics, formats, schedule)
- [ ] No metrics were hallucinated — all data sourced from webhooks
- [ ] User offered next action: plan next content cycle or exit
