# Step 2: Generate Draft

## What to Do
1. Based on the selected idea, generate a first draft
2. Adapt to channel:
   - **LinkedIn:** Professional but personal, 1300 chars max, hook-first, line breaks, emoji OK
   - **Telegram:** Casual, concise, links OK, can be longer
   - **YouTube:** Script format — hook, intro, sections, CTA
3. Apply tone: casual + witty, authentic, English only
4. Include a strong hook (first 2 lines)
5. End with CTA or question for engagement

## Draft Template
```
[Hook — grab attention in 2 lines]

[Body — value/story/insight]

[CTA — question/action/engagement prompt]

[Hashtags if applicable]
```

## Output
- First draft presented to user
- Ask: "How's this? Want to tweak anything?"
