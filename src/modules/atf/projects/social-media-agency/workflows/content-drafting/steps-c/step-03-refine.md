# Step 3: Refine

## What to Do
1. Take user feedback on the draft
2. Iterate — can go multiple rounds
3. User might say:
   - "Make it shorter"
   - "Change the hook"
   - "Add my personal experience about X"
   - "Too formal, make it more casual"
   - "Perfect, let's go"
4. Each iteration: show the updated draft, highlight what changed

## Rules
- Max 3 iterations before asking "Should we finalize this version?"
- Keep user's voice — don't over-polish
- If user says "good" / "done" / "perfect" → move to finalize

## Output
- User-approved final draft
