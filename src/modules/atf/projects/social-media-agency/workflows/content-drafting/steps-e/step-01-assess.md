# Step E-01: Assess (content-drafting)

## PURPOSE
Evaluate a requested edit to a drafted post before applying changes. Determine if the edit is a minor tweak or requires re-drafting.

## EXECUTION PROTOCOLS

1. [IDENTIFY] Determine the edit type:
   - **Content tweak:** Change wording, shorten, adjust tone (minor — within current draft)
   - **Hook change:** Replace the opening hook with a different framework
   - **CTA change:** Replace the call-to-action
   - **Framework swap:** Change one or more framework selections and regenerate
   - **Topic pivot:** Fundamentally change the angle (major — near-full redraft)
   - **Experience addition:** Incorporate a new personal experience into the draft

2. [ASSESS] Evaluate impact:
   | Edit Type | Regenerate? | Re-select frameworks? | Re-save? |
   |-----------|-------------|----------------------|----------|
   | Content tweak | No (manual edit) | No | Yes |
   | Hook change | Partial (hook only) | Hook only | Yes |
   | CTA change | Partial (CTA only) | CTA only | Yes |
   | Framework swap | Yes (full regenerate) | Yes (affected) | Yes |
   | Topic pivot | Yes (full regenerate) | Yes (all) | Yes |
   | Experience addition | Partial (weave in) | No | Yes |

3. [VALIDATE] Check feasibility:
   - Content tweak: Will result stay within 800–1600 chars?
   - Framework swap: Does the replacement exist in the CSV?
   - Topic pivot: Is the new angle still relevant to the scheduled post topic?
   - Iteration count: Will this push past the 3-iteration recommendation?

4. [REPORT] Present assessment to user:
   > "Edit: [description]. This will [regenerate/tweak] the draft. Iteration [N+1] of 3. Proceed? (haan/nahi)"

5. [PROCEED] If approved → Step E-02 (Apply Edit)
