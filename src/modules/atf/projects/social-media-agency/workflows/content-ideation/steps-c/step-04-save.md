# Step 4: Save to Notion

## What to Do
1. Save each approved idea to Notion **Content Calendar** database
2. Set properties:
   - 📌 Content Title
   - Main Channel
   - 📅 Go Live Date (if assigned)
   - Priority
   - Status: "Idea" or "Drafting"
3. If idea is raw/unscheduled, save to **Garden of Ideas** instead
4. Confirm to user: "Saved X ideas to your calendar"
