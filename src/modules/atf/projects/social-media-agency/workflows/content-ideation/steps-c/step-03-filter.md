# Step 3: Filter & Prioritize

## What to Do
1. From brainstorm output, user picks final 3-5 ideas
2. For each idea, confirm:
   - **Channel:** LinkedIn / Telegram / YouTube
   - **Format:** Post / Thread / Video / Poll / Story
   - **Priority:** High / Medium / Low
   - **Tentative date:** This week? Next week? Whenever?
3. User can modify any idea before saving
