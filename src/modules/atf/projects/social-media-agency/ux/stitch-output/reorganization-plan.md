# LinkRight SMA — Reorganization Plan

This document outlines the structure for organizing the 50+ screens into a logical developer handoff.

---

## 🟢 1. Ready for Development (Core Suite)
The final, highest-fidelity screens for the primary dashboard and management views.
- **Top row:** Light Mode (Dashboard, Posts, Detail, Analytics, Settings)
- **Bottom row:** High-Contrast Dark Mode (Dashboard, Posts, Detail, Analytics, Settings)

## 🔵 2. Interactive Journeys & Edge Cases (In-Progress / Specialized)
Organized by user journey ID (J1–J6).
- **J1: Content Ideation** (Briefs Selection, Loading, Empty/Error)
- **J2: Content Drafting** (Drafting Mode, Iterations, Revision History)
- **J3: Formatting & Preview** (Formatting Report, Auto-fix, LinkedIn Mockup)
- **J4: Review & Publish** (Batch Review, Confirmation Dialogs, Publish Failure)
- **J5: Analytics & Strategy** (AI Recommendations, Resurgence Alerts, Metric Collection)
- **J6: Settings & Config** (Fibonacci Sliders, Pillar Auto-adjust, Save Comparison)

## ⚪ 3. Empty State Journey (Day 0)
Ensures the "first-time user" experience is fully covered.
- Dashboard (Empty), Posts (Empty), Analytics (Empty)

## 🔴 4. Archived
Older versions and redundant iterations to keep the main workspace clean.
