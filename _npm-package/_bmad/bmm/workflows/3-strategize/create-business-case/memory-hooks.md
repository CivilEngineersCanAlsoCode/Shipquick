# Memory Hooks: Lean Business Case

## Sidecar Integration

- **Primary Sidecar**: `product-manager-sidecar`
- **Sidecar Root**: `_bmad/_memory/product-manager-sidecar`

## Capture Strategy

- **Mistake Tracking**: Append any functional or business assumptions that were challenged by the user to `common-mistakes.md`.
- **PRD Patterns**: Log high-quality benefit hypotheses or MVP definitions to `prd-patterns.md` as "Golden Examples".
- **Sizing Decisions**: Log any "Sizing" decisions (T-shirt sizes) to `feature-sizing.md`.

## Loading Hook

- Always read `common-mistakes.md` and `prd-patterns.md` during initialization.
