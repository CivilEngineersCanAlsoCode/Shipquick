# /015 Create Personas Workflow

**Goal:** Create detailed user personas to guide design and development decisions.

## PREREQUISITES

1. **Product Brief/PRD** -> Context on target users.

## INITIALIZATION

### 1. Identify Target Audience

Ask the user:
"Who is the primary audience for this project? Do we have specific segments in mind?"

## EXECUTION

### 2. Define Persona Attributes

For each persona, define:

- **Demographics**
- **Goals & Motivations**
- **Pain Points**
- **Tech Literacy**

### 3. Generate Artifact

Create `{planning_artifacts}/personas.md` with the discovered details.
