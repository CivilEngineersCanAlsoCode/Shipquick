# Quality & Documentation Excellence Handbook

---

## 1. Automated Testing (Playwright)

- **Patterns**: Use Page Object Model (POM) and Component-based selectors.
- **Resilience**: Use `data-testid` over fragile CSS selectors.

## 2. Adversarial QA Checklist

- Always check for: **Logic Flaws**, **Edge Cases**, **Security Vulnerabilities**, and **Performance Bottlenecks**.

## 3. Non-Functional Requirements (NFR)

- **Performance**: Monitor P95 latency.
- **Security**: RBAC and Data Encryption verification.
- **Accessibility**: WCAG 2.1 compliance.

## 4. Documentation Standards

- **Tone**: Professional, Clinical, and Precise.
- **Structure**: Use the "Five volumes" strategy for complex project documentation.
