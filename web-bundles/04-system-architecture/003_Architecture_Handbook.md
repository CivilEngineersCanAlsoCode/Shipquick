# Architecture & UX Design Handbook

---

## 1. Architecture Patterns

- **Clean Architecture**: Separation of concerns between Domain, Application, and Infrastructure.
- **Event-Driven**: Asynchronous communication between agents and core systems.

## 2. ADR Logic

Decision Records must include: **Context**, **Options Considered**, **Rationale**, and **Implementation Notes**.

## 3. UX Principles

- **Aesthetic**: Premium Dark Mode, Glassmorphism, and subtle micro-animations.
- **Simplicity**: AI complexity must be hidden behind intuitive "State Trees".

## 4. Security Framework

- **OAuth2**: For external integrations (GitHub/Overleaf).
- **Data Privacy**: GDPR/CCPA compliance for career data.
