# Agile Execution & Delivery Handbook

---

## 1. Feature Decomposition

- **Logic**: Decompose ART Features into 3-5 Team-level User Stories.
- **Criteria**: Use the **INVEST** principle (Independent, Negotiable, Valuable, Estimable, Small, Testable).

## 2. Gherkin Writing Standards

Acceptance Criteria must follow the **Given-When-Then** syntax.

- **Example**: `Given [context], When [action], Then [result]`.

## 3. Sprint Management

- **Planning**: Capacity planning and velocity tracking are mandatory.
- **Poker Pointing**: Relative estimation (1, 2, 3, 5, 8, 13) for complexity.

## 4. Engineering Standards

- **Clean Code**: SOLID principles and consistent documentation.
- **Defect Management**: Bugs must be categorized by Severity (Critical/High/Medium/Low).
